# Paperforge <small>v0.1.0</small>

> Markdown → Publication-grade PDF Publishing CLI

* **Full-Bleed Page Backgrounds** & edge-to-edge printing
* **Separate Page & Content Margins** globally and per-page
* **Mermaid & Vector SVG Charting** with custom color control
* **Pluggable Dual Engine**: System Browser + Direct PDFMake
* **Dynamic PDF Metadata Injection** via frontmatter & pdf-lib
* **1080×1080 Architecture Carousel Cards** for LinkedIn & slide decks
